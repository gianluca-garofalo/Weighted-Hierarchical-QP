# Bolt's Performance Journal

## 2025-02-15 - [Constraint Violation Select/Negation Optimization] **Learning:** In HQP, the inequality_hqp solver frequently loops over inactive constraints to check for constraint violations (slack). The previous implementation constructed temporary boolean array expressions using array negations (`!activeUpSet_` and `!activeLowSet_`) and `.select` statements to mask active bound values with infinities. However, since the slice checked only includes strictly inactive/available constraints, these active arrays are guaranteed to be entirely false, rendering the negation and `.select` expressions redundant. Removing them avoids temporary array instantiation and enables compiler auto-vectorization. **Action:** Always identify partitions or segments of state arrays where subset properties are known at compile/run time (e.g., active vs inactive sets) to eliminate redundant select/masking operations.
